# Patient Dashboard

A responsive, single-page patient dashboard focused on Jessica Taylor and based on the Coalition Technologies patient data API.

## Project files

- `index.html` — dashboard structure
- `css/style.css` — layout and responsive styling
- `js/script.js` — API request, patient data rendering, and blood pressure chart

## Run locally

Open this folder through a local web server, such as VS Code Live Server, then open `index.html` in the browser. The dashboard requests Jessica Taylor's details from the supplied API and loads Chart.js from jsDelivr.

The patient list on the left is part of the reference layout. Only Jessica Taylor's record is used for the profile, diagnosis history, vital signs, and chart.
